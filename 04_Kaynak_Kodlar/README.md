# Kaynak Kodlar

Bu klasördeki kaynak kodlar, projeyi devralacak bir mühendisin sistemi hızlı anlayabilmesi için
yorumlanmış halde sunulmuştur. Açıklamalar ayrı metin dosyalarında değil, ilgili kodun içinde yer alır.

Odak noktaları:
- dosya ve klasör yapısı
- model yükleme akışı
- segmentasyon maskeleri ve alan hesabı
- delik-somun eşleştirmesi
- veritabanı kayıt akışı
- API endpoint yapısı
- yalnız segmentasyon maskesi gösterilen güncel görselleştirme mantığı
