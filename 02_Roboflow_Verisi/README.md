# Roboflow Verisi

Bu projede kullanılan Roboflow görselleri, etiketleri ve veri yapılandırma
dosyaları gizlilik nedeniyle bu depoda paylaşılmamaktadır.

Projeyi çalıştırmak için veri setini yalnızca yetkili kaynaktan edinin ve yerel
olarak bu klasöre yerleştirin. Bu klasöre eklenen özel veri dosyaları
`.gitignore` kurallarıyla Git takibinin dışında tutulur.
